3.2  Architecture

SchoolHub follows a three-tier architecture. The React frontend sends requests to the Node.js backend API, which processes business logic and interacts with the PostgreSQL database through Prisma ORM. JWT secures all API endpoints. Docker packages the application, and Azure hosts the deployment.

3.3  Database Design

Key tables: users, roles, students, teachers, parents, classes, subjects, timetable, attendance, exams, marks, fees, assignments, submissions, notices, transport\_routes, and audit\_logs.

Relationships: A Class has many Students. A Teacher teaches many Subjects. An Exam has many Marks entries. Students are linked to Parents. Assignments are created by Teachers and submitted by Students.
