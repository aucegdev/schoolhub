4  DEVOPS IMPLEMENTATION AND CONCLUSION

4.1  DevOps Workflow

The CI/CD pipeline follows this flow: Developer pushes code to GitHub, which triggers Jenkins CI. Jenkins builds and tests the application, then Docker creates container images. Azure DevOps Pipeline deploys the containers to an Azure VM, and monitoring tracks application health.

\begin{verbatim}
Developer -> GitHub -> Jenkins CI -> Build & Test
  -> Docker -> Azure DevOps -> Azure Deployment -> Monitoring
\end{verbatim}

4.2  Git

Three branches: \textbf{main} (production), \textbf{develop} (integration), \textbf{feature/*} (modules). Developers create feature branches, submit pull requests, and merge after code review.

4.3  Docker

Frontend is built with Node.js and served via Nginx. Backend runs Node.js with Prisma. Docker Compose orchestrates all services including the PostgreSQL database.

4.4  Jenkins CI

Pipeline stages: Checkout (pull from GitHub), Install Dependencies, Lint (ESLint), Test (unit and integration tests), Build, Docker Build, and Push to container registry.

4.5  Azure and Deployment

The Azure pipeline pulls Docker images, stops existing containers, starts new ones using Docker Compose, and runs health checks. The application is deployed to an Azure VM with Nginx reverse proxy and secure environment variables.

4.6  Conclusion

SchoolHub successfully demonstrates a centralized web-based School Management System built with React, TypeScript, Node.js, Express.js, PostgreSQL, and Prisma ORM. It provides role-based access for Administrators, Teachers, Students, and Parents with modules for student management, attendance, examinations, assignments, fees, and communication. The project demonstrates a complete DevOps workflow using GitHub, Docker, Jenkins, and Azure DevOps for CI/CD deployment.
