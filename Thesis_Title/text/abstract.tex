ABSTRACT

SchoolHub is a web-based School Management System that automates academic and administrative operations for educational institutions. It manages student records, attendance, examinations, fees, timetables, and communication on a single platform. Built with React and TypeScript for the frontend, Node.js with Express.js for the backend, and PostgreSQL with Prisma ORM for the database. The project demonstrates DevOps practices using GitHub, Docker, Jenkins, and Azure DevOps for CI/CD deployment.
