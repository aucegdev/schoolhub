1  INTRODUCTION

1.1  Project Overview

SchoolHub is a web-based School Management System that automates academic and administrative operations for educational institutions. It manages student records, attendance, examinations, fees, timetables, and communication on a single platform. The frontend uses React and TypeScript, the backend uses Node.js with Express.js, and the database uses PostgreSQL with Prisma ORM. The project also demonstrates DevOps practices with GitHub, Docker, Jenkins, and Azure DevOps.

1.2  Problem Statement

Many schools rely on manual processes or disconnected software for daily operations. This causes data duplication, poor report generation, weak communication, and frequent human errors. A centralized digital platform is needed to manage all school operations efficiently.

1.3  Objectives

The objectives of the project are:

\begin{itemize}
\item Build a single platform for students, teachers, attendance, exams, and fees.
\item Implement role-based access for Administrators, Teachers, Students, and Parents.
\item Automate timetables, attendance, and examination processing.
\item Generate reports for attendance, exams, and fees.
\item Demonstrate CI/CD with Docker, Jenkins, and Azure DevOps.
\end{itemize}

1.4  Scope

\textbf{Included:} Student, Teacher, Class, Subject, Timetable, Attendance, Examination, Assignment, Fee, Transport, Notice Board, Dashboard, Reports, and CI/CD Pipeline.

\textbf{Excluded:} Online payment gateway, mobile app, SMS/email notifications, AI chatbot, library management.

1.5  Expected Outcomes

Automated school operations, improved data accuracy, real-time access to information, secure role-based access, and a scalable foundation for future enhancements.
