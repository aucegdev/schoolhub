# SchoolHub - Smart School Management System

**Manage. Learn. Grow.**

SchoolHub is a modern web-based School Management System built with React, TypeScript, Node.js, and PostgreSQL. It streamlines school operations through secure role-based access for administrators, teachers, students, and parents.

## Tech Stack

- **Frontend:** React + TypeScript + Vite + Tailwind CSS + shadcn/ui
- **Backend:** Node.js + Express + TypeScript
- **Database:** PostgreSQL + Prisma ORM
- **Authentication:** JWT + RBAC
- **DevOps:** Docker, Jenkins, Azure DevOps, Ansible
- **Cloud:** Azure
