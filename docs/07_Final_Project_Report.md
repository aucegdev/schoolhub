## 1. Introduction
SchoolHub is a web-based School Management System developed using React, TypeScript, Node.js, Express, and PostgreSQL. It digitizes school operations including admissions, attendance, examinations, fees, timetables, and communication through a secure, role-based interface.

## 2. Objectives
- Automate daily school administrative tasks
- Provide role-based access for different stakeholders
- Generate reports and analytics for informed decision-making
- Demonstrate DevOps practices (CI/CD, Docker, Cloud Deployment)
